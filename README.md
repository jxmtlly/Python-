# 🏫 Sistema de Notas - Elite Way School

Uma aplicação interativa desenvolvida em Python que automatiza o processo de gestão escolar. 
O sistema recebe as notas e frequências de um aluno, valida os dados em tempo real, calcula as médias e gera um boletim detalhado com a situação final (Aprovado ou Reprovado) para cada disciplina.

## 🚀 Funcionalidades Principais
* ⚙️ **Validação de Dados:** Garante que apenas notas entre 0 e 10 e frequências entre 0% e 100% sejam aceites.
* 📊 **Cálculo de Médias:** Processamento automatizado das avaliações por disciplina.
* 🎯 **Tomada de Decisão:** Avaliação automática com base nos critérios de nota mínima (6.0) e frequência mínima (75%).
* 📄 **Relatório Automatizado:** Geração de um boletim escolar formatado diretamente no terminal.
